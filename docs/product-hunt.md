### Description

Control a tiled Mac desktop from the keyboard. Mac Ricing pairs Rift with ten workspaces, a native bar that shows occupied workspaces and the apps on your current one, a quick launcher, and an optional visualizer for the sound playing on your Mac. It runs locally on Apple silicon with macOS 26. Install from GitHub and use the included uninstall script when you want to remove it.

### Maker comment

Hey Product Hunt! I wanted my Mac to feel as easy to drive from the keyboard as the i3 setup I was used to. I wanted to know where my windows were, move them without reaching for the mouse, and get an empty workspace out of the way as soon as I left it. That’s where Mac Ricing started.

Rift handles the tiling. I built the workspace bar, desktop frame, and launcher around it. Press Option and a number to jump to a workspace. The bar shows only the workspaces you’re using and the one you’re on. I also added a little waveform that reacts to the audio playing on the Mac when you turn it on.

I’ve been using it on an Apple silicon Mac mini on macOS 26.7.3. The GitHub repo has the setup steps, shortcut sheet, and an uninstall script.

If you try it, what was the first shortcut you wanted to change? I’d also like to hear where a fresh install gets confusing.
